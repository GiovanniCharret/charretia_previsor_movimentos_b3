Como cada versão funciona

Cada versão da tela é uma resposta a uma pergunta diferente, com parâmetros próprios. Esta página guarda os dois — a pergunta e os números — para que uma versão antiga possa ser reconstruída sem arqueologia de commit.

{{VERSOES}} {{BLOCOS}}

Uma versão nova nasce quando um achado muda a pergunta, não quando um número muda de valor. Recalibrações entram como nota na versão vigente.
